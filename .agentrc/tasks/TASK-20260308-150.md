# S10-01: Agent Profile Manager page

## Description

Create an Agent Profile Manager UI page/panel for mentat. The backend API already exists at /api/agents with full CRUD.

Existing frontend context:
- AgentPicker.tsx and AgentRoster.tsx exist for session-level agent selection
- api.ts has fetch helpers, types.ts has interfaces
- App uses React 19 + Tailwind 4 + shadcn-style components + Lucide icons
- Dark theme throughout

Create ui/src/components/settings/AgentProfileManager.tsx:
1. List view: show all agent profiles as cards (name, slug, avatar, description, can_execute badge, mode count)
2. Detail/edit view: click a profile to open edit form with:
   - Name, slug, avatar URL, description
   - System prompt (large textarea with monospace font)
   - Default model selector
   - can_execute toggle
   - MCP servers (JSON editor or tag input)
   - Tool permissions (JSON editor or structured allow/deny list)
3. Modes section within detail view:
   - List modes for this agent (GET /api/agents/:id/modes)
   - Add mode form: name, slug, prompt_addendum (textarea), tool_overrides (JSON)
   - Delete mode
4. Create new profile button
5. Delete profile (with confirmation dialog)

Wire into the app navigation — add a "Settings" or "Agents" route accessible from NavRail.

Use React Query for data fetching. Match existing component patterns (see LeftSidebar.tsx, WorkflowPanel.tsx for reference).

AGENT RULE: Update this task to 'doing' when you start, 'done' when complete, or 'blocked' with a description if stuck. Use Volon MCP with project_id=mentat.

## Acceptance Criteria

- Agent list displays all profiles from API
- Can create, edit, and delete agent profiles
- Can manage modes per agent
- System prompt editable in textarea
- Tool permissions editable
- Accessible from nav
- Dark theme consistent with rest of app
