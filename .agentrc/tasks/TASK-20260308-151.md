# S10-02: Skills Browser + Agent Skill Assignment UI

## Description

Create a Skills Browser UI and integrate skill assignment into the Agent Profile Manager. Backend API exists at /api/skills with full CRUD, plus /api/agents/:id/skills for assignment.

Create ui/src/components/settings/SkillsBrowser.tsx:
1. Grid/list of all skills (GET /api/skills) showing: name, slug, category, description, tool_bindings count, is_builtin badge
2. Click skill to see detail: full description, tool bindings (server + tool name), input schema
3. Create custom skill form: name, slug, category dropdown, description, tool bindings editor
4. Edit/delete non-builtin skills

Integrate into AgentProfileManager (S10-01):
5. Add a "Skills" tab/section in the agent detail view
6. Show assigned skills for this agent (GET /api/agents/:id/skills)
7. "Add Skill" button opens a picker/dropdown of available skills
8. Remove skill button per assigned skill
9. Per-agent skill config override (JSON editor, optional)

API endpoints to use:
- GET /api/skills — list all
- POST /api/skills — create
- GET/PUT/DELETE /api/skills/:id
- GET /api/agents/:id/skills — list agent's skills
- POST /api/agents/:id/skills — assign {skill_id}
- DELETE /api/agents/:id/skills/:skillId — remove

AGENT RULE: Update this task to 'doing' when you start, 'done' when complete, or 'blocked' with a description if stuck. Use Volon MCP with project_id=mentat.

## Acceptance Criteria

- Skills grid displays all skills with category filtering
- Can create custom skills
- Agent detail shows assigned skills
- Can assign/remove skills from agents
- Tool bindings visible per skill
- Builtin skills can't be deleted
