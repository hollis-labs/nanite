# S10-03: Prompt Template Editor + Agent Template Assignment

## Description

Create a Prompt Template Editor UI and integrate assignment into Agent Profile Manager. Backend API exists at /api/prompt-templates with full CRUD.

Create ui/src/components/settings/PromptTemplateEditor.tsx:
1. List all prompt templates (GET /api/prompt-templates) showing: name, slug, scope badge (system/mode/skill/context), priority, is_builtin badge
2. Click template to edit: 
   - Name, slug, scope dropdown
   - Template body (large textarea/code editor with monospace)
   - Variables definition (JSON editor showing [{name, type, required, default, description}])
   - Priority (number input)
   - Live preview: show rendered template with sample variable values
3. Create new template form
4. Delete non-builtin templates

Integrate into AgentProfileManager:
5. Add "Prompt Templates" tab/section in agent detail view
6. Show assigned templates for agent (GET /api/agents/:id/prompt-templates), ordered by priority
7. "Assign Template" button opens picker
8. Remove template button
9. Show composed preview: call the backend or simulate assembly of all assigned templates with sample variables

API endpoints:
- GET/POST /api/prompt-templates
- GET/PUT/DELETE /api/prompt-templates/:id
- GET /api/agents/:id/prompt-templates
- POST /api/agents/:id/prompt-templates — assign {template_id}
- DELETE /api/agents/:id/prompt-templates/:templateId

AGENT RULE: Update this task to 'doing' when you start, 'done' when complete, or 'blocked' with a description if stuck. Use Volon MCP with project_id=mentat.

## Acceptance Criteria

- Template list with scope/priority sorting
- Template editor with monospace textarea
- Variables definition editable
- Live preview with sample values
- Agent detail shows assigned templates in priority order
- Can assign/remove templates from agents
- Builtin templates can't be deleted
