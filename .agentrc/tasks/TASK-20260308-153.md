# S10-04: Tool/MCP Dashboard

## Description

Create a Tool/MCP Dashboard showing connected servers, discovered tools, and refresh capability. Backend API already exists from MC-S8 and MC-S9.

Create ui/src/components/settings/ToolDashboard.tsx:
1. MCP Servers section: show connected servers (GET /api/tools/servers) with name, transport type, tool count, connection status
2. Tools list: show all discovered tools (GET /api/tools) with name, server, description. Filterable by server.
3. Refresh button: POST /api/tools/refresh — show discovery diff (added/removed counts) as a toast or inline result
4. Tool detail: click a tool to see full description, input schema (formatted JSON), and which skills reference it
5. Intent test: input field to test tool selection (POST /api/tools/select with intent string) — shows which tools would be selected for a given query

Add api.ts functions for:
- fetchTools(), fetchToolServers(), refreshTools(), selectTools(intent)

AGENT RULE: Update this task to 'doing' when you start, 'done' when complete, or 'blocked' with a description if stuck. Use Volon MCP with project_id=mentat.

## Acceptance Criteria

- Server list with status indicators
- Tools list filterable by server
- Refresh triggers discovery and shows diff
- Tool detail shows schema
- Intent test returns selected tools
- All wired to existing API endpoints
