# S10-05: Settings page layout + NavRail integration

## Description

Create a Settings page that hosts all the management UIs (Agent Profiles, Skills, Prompt Templates, Tools) and wire it into the app navigation.

1. Create ui/src/components/settings/SettingsPage.tsx:
   - Tab-based layout with 4 tabs: Agents, Skills, Prompts, Tools
   - Each tab renders the corresponding component (AgentProfileManager, SkillsBrowser, PromptTemplateEditor, ToolDashboard)
   - Responsive: tabs become sidebar navigation on wider screens
   - Consistent with app's dark theme

2. Add Settings route:
   - Add to App.tsx routing (if using React Router) or toggle in AppShell
   - Settings icon (Cog/Settings from Lucide) in NavRail
   - Clicking Settings replaces the chat view with SettingsPage
   - Back/close button to return to chat

3. Update NavRail.tsx:
   - Add Settings button with tooltip
   - Active state indicator when on settings page
   - Position at bottom of NavRail (below existing icons)

This task should be done FIRST or in parallel with the other S10 tasks since it provides the layout container.

AGENT RULE: Update this task to 'doing' when you start, 'done' when complete, or 'blocked' with a description if stuck. Use Volon MCP with project_id=mentat.

## Acceptance Criteria

- Settings page with tab navigation
- NavRail has Settings icon
- Clicking toggles between chat and settings views
- Each tab renders placeholder until real components are built
- Back to chat works
- Dark theme consistent
