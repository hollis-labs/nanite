# /bootstrap-update

Regenerate `.agentrc/bootstrap.md` from ground truth (Volon tasks, config). Produces a deterministic snapshot of current iteration state.

## Usage

```
/bootstrap-update [--iteration <N>]
```

- `--iteration`: explicit iteration number (default: auto-increment from current bootstrap)

## Steps

1. **Read config.** Extract from `agentrc.yaml` (or use defaults):
   - `bootstrap.path` -> `.agentrc/bootstrap.md`
   - `bootstrap.history_path` -> `.agentrc/bootstrap/history`
   - `pcc.location` -> `.agentrc/pcc`

2. **Read ground truth.** Scan all sources:
   - Volon tasks via `volon_tasks_list` — count by status (`todo`, `doing`, `paused`, `blocked`, `done`)
   - `.agentrc/pcc/global/04_backlog.md` — deferred items (if exists)
   - `config/repos.yaml` — managed projects

3. **Resolve iteration number.**
   - Read existing bootstrap, find `Iteration` and increment by 1
   - Or use explicit `--iteration N` argument
   - Default: 1

4. **Compose bootstrap.md.** Write sections in order:

   ```markdown
   # Mentat — Bootstrap (Iteration N)

   > Auto-generated by `/bootstrap-update` on YYYY-MM-DD HH:MM.
   > Source of truth: Volon tasks and `config/`.

   ## Task counts

   | Status  | Count |
   |---------|-------|
   | todo    | X     |
   | doing   | X     |
   | paused  | X     |
   | blocked | X     |
   | done    | X     |
   | **total** | **X** |

   ## Top 3 next tasks

   1. **TASK-ID** (priority) — title
   2. **TASK-ID** (priority) — title
   3. **TASK-ID** (priority) — title

   ## Blockers

   - **TASK-ID** — blocker description
   - (or "None.")

   ## Quick start

   ```bash
   # 1. Verify services
   curl -sf http://127.0.0.1:8095/ && echo "Hadron: ok"
   curl -sf http://127.0.0.1:8085/v1/tasks && echo "Volon GUI: ok"

   # 2. Pick highest-priority open task and begin work
   ```

   ## Config snapshot

   - Hadron: <status/url>
   - Volon GUI: <status/url>
   - Projects: <count> configured
   ```

5. **Write files.**
   - Write to `.agentrc/bootstrap.md`
   - If `.agentrc/bootstrap/history/` directory exists, write copy as `bootstrap-iteration-<N>.md`

6. **Set frontmatter.** Ensure bootstrap has YAML frontmatter:
   ```yaml
   ---
   updated: YYYY-MM-DD
   iteration: N
   paused_task_id: null
   ---
   ```

7. **Output.** Print:
   - List of changed files
   - Full contents of `.agentrc/bootstrap.md`
   - End with DONE

## Invariants

- Never fabricate task counts — always query Volon for actual data
- Never modify tasks — this command is read-only for tasks
- Always include the Quick Start section
- Always preserve `paused_task_id` from current bootstrap if a task is actually paused
- Iteration number must always increase
