Key Design Decisions

A

SSE for live updates

Real-time step transitions via /api/workflows/events. Steps can complete in <1s — polling would miss them. Follows the same SSE pattern as chat streaming.

B

In-memory RunStore (ring buffer)

Last 50 runs kept in memory. No SQLite table needed — workflows are ephemeral by nature. Backend executor hooks into the store via its existing EventHandler.

C

Filter: All / Active toggle

Default to "Active" showing only running pipelines. "All" shows recent completed/failed runs from the ring buffer. Keeps the panel focused.
