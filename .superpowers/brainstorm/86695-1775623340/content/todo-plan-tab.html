Shared Features (both approaches)

  • Drag-and-drop reorder (grip handle)
  • Checkbox toggle with inline feedback field on un-done
  • "Send Changes" button — inactive until changes made, batched diff
  • Auto-inject on next user message if forgotten
  • Toast notification above composer on sync
  • Scope selector: Session (default in chat) / Project
  • Matching envelope cards for inline chat interaction
  • Events emitted: todo.updated, plan.updated, plan.approved
