Filter Pill Behavior

Try clicking the pills in the mockup to see the guard logic in action.

  • ● Both pills on by default — shows all items grouped by type
  • ● Click a pill to toggle it off — hides that group
  • ● Guard: If only one pill is active and you click it, the other pill turns on instead. Prevents empty state — always at least one active.

Search

Filters both workspaces and projects by name. Respects active pills — if "Workspace" is off, workspace items stay hidden even if they match.

Selection

Clicking a workspace switches the active workspace (and resets project to "All Chats"). Clicking a project switches just the project filter. "All Chats" clears the project filter.

NavRail N Logo

Branded N in primary color. Click navigates to home/main screen. Workspace selector is fully removed from the NavRail.

Keyboard

Cmd+K could optionally open this combobox (in addition to command palette), or a dedicated binding.
