**Confirmed true: nothing in the chat/prompt-assembly pipeline reads `agent_known_skills`.** Grepped every call site of `ListAgentKnownSkills`/`GetAgentKnownSkill` across the repo — the only callers are the REST API handlers in `internal/api/agent_capabilities.go` themselves.
