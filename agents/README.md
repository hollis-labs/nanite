# Agents

Specialist agents maintained with Nanite. Each folder is a complete agent
directory: run it standalone with `nanite -C agents/<name>`, or bind it into a
host app (for example a Surface module), which supplies the model, gateway and
tools. Built from `examples/specialist`; CI validates every folder here.

| Agent | Owns |
|---|---|
| `nanite-setup-expert` | Setting up Nanite agents and Surface ADE agents |
