# Surface Modules

Fetch `design-surface-workflow` for the Surface-owned workflow design procedure. Read the bundled `surface-module-contract`, `surface-workflow-design`, and `surface-module-ui` context documents as needed. `surface-module-pack` records the source revision and pack version; check the target Surface contract before implementing.

The pack explains module mechanics; this agent's charter still owns its role. Deliver a workflow design and a review handoff; the Surface team implements the module and the design team owns its visual components.
